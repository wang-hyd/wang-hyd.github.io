零成本搭建专属端到端加密文件分享服务

发表于 2026-10-26 分类于 技术分享

零成本搭建专属端到端加密文件分享服务：Cloudflare Workers + D1 + R2 部署 Parcel 避坑全记录

1. 项目简介

Parcel 是一款轻量、安全的私有文件共享系统。其主要特性包括：

  • 端到端加密（E2EE）：文件在浏览器端完成加解密，云端仅存储密文。

  • 完全 Serverless：基于 Cloudflare 生态（Workers + D1 + R2），无需任何物理服务器。

  • 零成本运维：在 Cloudflare 免费额度内完全够用（R2 10GB 免费存储 + 无出站流量费 + Workers 免费调用配额）。

  • 权限与生命周期管理：支持阅后即焚、下载次数限制、到期自动清理，管理员需通过强密码与两步验证（TOTP）登录管理，普通接收者无需账号即可解密下载。

2. 免费额度与防超额安全说明

8. Windows 部署踩坑总结 (Troubleshooting)

  1. **'.' 不是内部或外部命令**：

    • 原因：项目构建脚本默认使用 Linux 语法 ./scripts/build-v3.sh。

    • 解法：在 PowerShell 中直接调用 Git 的 bash 解释器执行：
      & "C:\Program Files\Git\bin\bash.exe" ./scripts/build-v3.sh

  2. **Configure the FILES R2 bucket binding**：

    • 原因：Worker 源码中硬编码读取的 R2 Binding 名称为 FILES，若在 wrangler.json 中配置为 R2 或其他名称会导致部署失败。

    • 解法：将 wrangler.json 内 r2_buckets 的 "binding" 值修改为 "FILES"。

  3. **No migrations present at ...\migrations**：

    • 原因：Wrangler 默认在根目录寻找 migrations 文件夹，而 Parcel v3 的迁移 SQL 存放在 cloudflare/v3/migrations。

    • 解法：在 d1_databases 对象内显式增加 "migrations_dir": "cloudflare/v3/migrations" 配置项。
